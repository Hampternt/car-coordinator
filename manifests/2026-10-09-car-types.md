## Goal

Each car says whether it is a normal van or a lift car (a car with a tail lift), shown as an icon wherever the car appears. A lift car parked anywhere but a lift spot (Spot 4, Spot 5 or the Gate) raises a warning like the existing clashes: listed in the amber box and striping the row, **never blocking** the choice.

## Migration plan (before any change to saved state)

- **Who holds the old shape:** every browser and save file on schema 6 or earlier.
- **What they see after the upgrade:**
  - every car is a normal van;
  - positions named **Spot 4**, **Spot 5** and **Gate** start ticked for lift cars (matched by name, ignoring case and spaces); every other position starts unticked;
  - nothing else changes, and no warning appears until a car is marked as a lift car.
- **Between PCs on different versions:**
  - an older copy opening a schema-7 plan or save file keeps the extra fields untouched only if its `normalise` keeps unknown fields. **To check before building:** if it drops them, the update note must say "update both PCs";
  - a share code from the new version read by an older one loses the types, and says nothing about it;
  - the shared plan makes the older copy read-only, so it can never write the fields away.
- **Offered or forced:** the new fields are added with defaults and need no question; nothing existing is renamed or removed. The update note names the three spots that start ticked.

## Test it yourself (outline)

1. Mark two cars as lift cars on the Cars tab.
2. Put one on a route at Spot 4 and the other at Spot 1. Only the Spot 1 route warns.
3. Untick Spot 4's Lift cars box, and its route warns too.
4. Make a share code, then read it back: the types survive.
