Car Coordinator: recovery

For when the app itself will not start. This page shares no code with the app and changes nothing: it lists what this browser holds for Car Coordinator, and downloads each piece as a file, exactly as it is stored.

A plan, an archive or a backup downloaded here loads again with Import a copy… on the Data tab, in this browser or another. Everything listed is kept in this browser only: it is gone once this browser’s data is cleared, and another browser never had it.
